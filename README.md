The Quiet Stacks is a top-down stealth heist in an old university library: sneak past four patrolling librarians and their lantern vision cones, hide behind tall bookshelves, steal three rare manuscripts, and escape through the reading-room window unseen.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD / arrows to move, SHIFT to run (loud!), click to walk, P to pause, R to restart.

Four librarians patrol with lantern cones: Mara, Tomas, Ilya and Wren. Tall bookshelves block sight; lamp light makes you easy to spot, shadow hides you. A guard who spots you chases — break line of sight and they investigate, then return to patrol.
